Who this certification is for:

Microsoft describes the candidate as having subject matter expertise in integrating and modeling data, building and deploying optimized pipelines, and troubleshooting and maintaining workloads in Azure Databricks, plus experience applying data quality and data governance best practices in Unity Catalog, using SQL and Python, Git-based SDLC practices, and familiarity with Microsoft Entra, Azure Data Factory and Azure Monitor.

Microsoft Learn lists a 120-minute time limit and no question count, and the exam may include interactive components. Microsoft publishes domain weights as ranges: 15-20%, 15-20%, 30-35% and 30-35% in the order listed. Skills measured version effective March 11, 2026. The exam is offered in English, Japanese, Chinese (Simplified), Chinese (Traditional), Korean, German, French, Italian, Portuguese (Brazil) and Spanish. Most questions cover generally available features; Preview features may appear if commonly used.
