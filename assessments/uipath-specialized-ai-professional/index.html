Who this certification is for:

UiPath's own exam description document defines the target audience as automation developers involved with Document Understanding and Communications Mining projects, plus technical roles requiring automation developer expertise with a DU/CM focus — automation architects, solution designers, solution architects, and process automation architects. The Minimally Qualified Candidate has completed automation projects using Communications Mining and extensive Document Understanding experience, completed recommended UiPath Academy training, completed at least one Communications Mining project, and is technically proficient enough to work independently.
