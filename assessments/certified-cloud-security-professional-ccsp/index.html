About the Official Certified Cloud Security Professional (CCSP) Exam

Sourced directly from the official Certified Cloud Security Professional (CCSP) Exam Guide, published by ISC2 — Live version effective August 1, 2026.

Questions
100–150 items via Computerized Adaptive Testing (CAT); unscored pretest items are interspersed throughout and are not distinguishable from scored items (CAT format effective October 1, 2025)
Time Limit
3 hours
Passing Score
700 out of 1000 points (scaled score; raw item weighting is not disclosed)
Registration Fee
$599 (Americas/APAC pricing; regional pricing varies by country)
Delivery
Pearson VUE — onsite-proctored at an authorized test center (ISC2 has confirmed no ISC2 exam, including CCSP, is offered via OnVUE online proctoring, citing integrity findings from its online-proctoring pilot programs)
Validity
3-year certification cycle requiring 90 CPE credits (60 Group A credits directly relevant to the CCSP domains, plus 30 credits from Group A or B); a single $135 annual maintenance fee covers any combination of ISC2 certifications held, including CCSP, regardless of how many are held simultaneously

Official exam domains this diagnostic mirrors:

  • Cloud Concepts, Architecture and Design 17%
  • Cloud Data Security 20%
  • Cloud Platform and Infrastructure Security 17%
  • Cloud Application Security 16%
  • Cloud Security Operations 17%
  • Legal, Risk and Compliance 13% (effective August 1, 2026 — Cloud Application Security and Cloud Security Operations each shifted one point from the prior 17%/16% split)

Who this certification is for:

ISC2 describes the CCSP as validating the advanced technical skills needed to design, manage, and secure data, applications, and infrastructure in the cloud; the typical audience includes cloud security architects and engineers, security administrators, systems/enterprise security architects, security consultants and managers, and other IT and cloud professionals responsible for an organization's cloud security posture.

Requires a minimum of 5 years of cumulative, paid IT experience, including 3 years in information security and 1 year in one or more of the six CCSP domains. Up to one year may be waived with a relevant post-secondary degree; CSA's CCSK credential may substitute for one year of the required domain experience; an active CISSP credential satisfies the entire CCSP experience requirement. Candidates who lack the required experience may still sit and pass the exam to become an Associate of ISC2, with 6 years to earn the required experience. ISC2 periodically updates the exam via a formal Job Task Analysis (JTA) to keep content aligned with current practitioner roles and responsibilities.
