About the Official AWS Certified AI Practitioner Exam

Sourced directly from the official AWS Certified AI Practitioner Exam Guide, published by Amazon Web Services (AWS) — Version 1.1, effective April 30, 2026.

Questions
65 total questions (50 count toward the score; 15 are unscored pretest items used by AWS to evaluate future exam content and are not identified to the candidate)
Time Limit
90 minutes
Passing Score
700 on a scaled 100–1,000 range (compensatory scoring across the whole exam; no minimum is required in any individual domain)
Registration Fee
$100 USD
Delivery
Pearson VUE — available both at an authorized testing center and via online proctoring
Validity
3-year certification cycle; recertify by passing the current version of this exam, or by earning AWS Certified Machine Learning Engineer - Associate, before expiration

Official exam domains this diagnostic mirrors:

  • Applications of Foundation Models 28%
  • Fundamentals of GenAI 24%
  • Fundamentals of AI and ML 20%
  • Guidelines for Responsible AI 14%
  • Security, Compliance, and Governance for AI Solutions 14%

Who this certification is for:

AWS recommends up to 6 months of exposure to AI/ML technologies on AWS; the target candidate uses AI/ML solutions on AWS but does not necessarily build them. There is no formal certification prerequisite, though AWS recommends familiarity with core AWS services, the shared responsibility model, IAM, and AWS pricing models.

Developing or coding AI/ML models, hyperparameter tuning, building AI/ML pipelines, and implementing governance frameworks are explicitly listed as out of scope for the target candidate. Version 1.1 (effective April 30, 2026) added objectives on agentic AI, Model Context Protocol (MCP), multi-agent communication patterns, token-based pricing, context engineering, model distillation, and hallucination-grounding techniques — domain weights and total question counts were unchanged by this revision. A separate, unrelated static PDF mirror of this exam guide found during validation displayed a mismatched "Version 1.4" label and older domain content; the authoritative source (docs.aws.amazon.com) confirms Version 1.1 as current, and this file is validated against that authoritative version only.
