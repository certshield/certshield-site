About the Official AWS Certified DevOps Engineer - Professional Exam

Sourced directly from the official AWS Certified DevOps Engineer - Professional Exam Guide, published by Amazon Web Services (AWS).

Questions
75 total questions (65 count toward the score; 10 are unscored pretest items used by AWS to evaluate future exam content and are not identified to the candidate)
Time Limit
180 minutes (3 hours)
Passing Score
750 on a scaled 100–1,000 range (compensatory scoring across the whole exam; no minimum is required in any individual domain)
Registration Fee
$300 USD (holders of an active AWS certification may be eligible for a 50% discount voucher)
Delivery
Pearson VUE — available both at an authorized testing center and via online proctoring
Validity
3-year certification cycle; recertify by passing the current version of this exam, or any AWS certification exam at the same or a higher tier, before expiration

Official exam domains this diagnostic mirrors:

  • SDLC Automation 22%
  • Configuration Management and IaC 17%
  • Resilient Cloud Solutions 15%
  • Monitoring and Logging 15%
  • Incident and Event Response 14%
  • Security and Compliance 17%

Who this certification is for:

AWS recommends 2 or more years of experience provisioning, operating, and managing AWS environments, plus experience with the software development lifecycle and programming and/or scripting. There is no certification prerequisite.

Advanced networking knowledge (advanced routing algorithms, failover techniques), giving deep-level security recommendations to developers, designing/querying/optimizing databases, and developing full-stack application code are explicitly listed as out of scope for the target candidate. Unlike several other current AWS exam guides, AWS's own DOP-C02 exam guide does not publish a dated version number or revision history -- this validation is against the live, undated current guide.
