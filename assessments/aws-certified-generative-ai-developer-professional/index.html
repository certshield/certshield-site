About the Official AWS Certified Generative AI Developer - Professional Exam

Sourced directly from the official AWS Certified Generative AI Developer - Professional Exam Guide, published by Amazon Web Services (AWS) — Version 1.0.

Questions

Validity
3-year certification cycle; recertify by passing the current version of this exam, or any AWS certification exam at the same or a higher tier, before expiration

Who this certification is for:

AWS recommends 2 or more years of experience building production-grade applications on AWS or with open-source technologies, general AI/ML or data engineering experience, and 1 year of hands-on experience implementing generative AI solutions. There is no certification prerequisite, though AWS suggests candidates may benefit from first holding AWS Certified AI Practitioner, AWS Certified Solutions Architect - Associate, AWS Certified Machine Learning Engineer - Associate, or AWS Certified Data Engineer - Associate.

There is no formal enrollment prerequisite, though AWS designs this exam for practitioners already building production GenAI workloads on AWS rather than newcomers to the platform. Model development and training, advanced ML techniques, and data engineering/feature engineering are explicitly listed as out of scope for the target candidate. AIP-C01 briefly ran as a beta exam (beta concluded March 2026) before this current Version 1.0 general-availability release.
