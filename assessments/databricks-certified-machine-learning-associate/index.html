Who this certification is for:

Databricks' own exam guide describes the ideal candidate as someone who can use Databricks to perform basic machine learning tasks, using Unity Catalog and select features of MLflow, exploring data and performing feature engineering, building models through training, tuning, evaluation, interpretation, and selection, and deploying and monitoring machine learning models.

Unscored calibration questions may appear on the real exam; extra time is already factored in to account for them. Databricks' transition guide (updated November 10, 2026) covers two versions: the current exam through December 8, 2026 (48 scored questions; sections 38% / 19% / 31% / 12%) and the new exam from December 9, 2026 (45 scored questions), which is the version this set follows. The new exam is offered in English first, with other languages to follow.
