Who this certification is for:

Databricks' own exam guide describes this credential as assessing an individual's ability to design, assemble, and govern the information that AI agent systems receive at inference time using Databricks — structuring instructions and system prompts, configuring retrieval systems such as AI Search, designing memory architectures using Lakebase and MLflow, integrating agents with tools via protocols such as MCP, managing context window constraints through compaction and trimming, and governing what enters the context via Unity Catalog's metadata layer (data quality, PII handling, policy enforcement), across single- and multi-agent, long-horizon workflows.

No formal prerequisites; related Databricks Academy course attendance and 6 months of hands-on experience are highly recommended. No official exam code has been published for this certification as of this validation date.
